2026-005-小型作业集合

机械设计制造及其自动化专业的课程作业与课余练习归档，按文件夹收录传感器、机械设计、控制工程、数控、机器人学、机械制造及若干软件与写作材料。

项目内容

  1. 传感器课程作业 a2-传感器课程作业 为传感器期末复习材料，含宜家流水线 50mm 木板厚度测量及 WiFi 传输方案，以及专项复习 PDF。

  2. 机械设计大作业 a3-机械设计大作业 为机械设计课程大作业，含课程讲义 PC-机械设计-1.pdf、带传动设计计算表，以及齿轮、涡轮、传动轴、带轮、轴承、螺钉、键与键槽等零件图纸与模型；sty作业 为行星减速器装配及零件 DWG。

  3. 机械设计及控制工程小作业 a4-机械设计及控制工程小作业 按次收录作业，现有第一次至第十九次、第二十一、二十二、二十四至二十六次。内容包括行星滚柱丝杠说明、齿轮与涡轮模型、传动轴图纸、键槽选择、视觉厚度识别压缩包，以及若干作业截图与视频。目录内注明第 20、23 次作业及电机控制大作业尚未完成。

  4. 控制工程小作业 a5-控制工程小作业 为控制工程课程材料，含倒立摆、弹簧阻尼系统响应、牛顿力学 / 质量—弹簧—阻尼、电机位置控制、画圆与定速巡航等 Simulink 模型；视觉厚度识别含 Solid Edge 模型、汇报与 BOM；另有拉氏变换等考试复习资料，以及并行作业中的 C# 与 Solid Edge 相关工程。

  5. 凸优化作业 a6-凸优化作业 含最优化作业 PDF、最优化论文理解作业，以及论文 Received Signal Strength-Based Wireless Localization via Semidefinite Programming；配套 C# 控制台程序按该文复现非协作 RSS 无线定位的 SDP 估计与 CRLB 计算。

  6. 控制工程作业良子开车 a7-控制工程作业良子开车 为悬挂 / 减速带工况的控制工程作业。MATLAB 脚本按良子与焖子质量、车轮等效质量、刚度与阻尼约束计算减速带激励下的响应；另有报告最终版本（陈煜暄 23414030110）、良子开车(2).docx 及 WinForms 工程 Hanging Solver。

  7. Solid Edge 学习 a8-SoulidEdge学习 为 Solid Edge 课堂与练习文件：Class Files 含拉伸、放样、扫描、装配等教学零件；hw 含酒杯、管道、相贯线、洞洞板、齿轮及多套装配；EX 含铰链、连杆、收纳盒等练习件。

  8. 机械制造作业及其复习 a9-机械制造作业及其复习 含 机械制造作业.docx 与 机械制造技术复习-A4.docx。

  9. 数控技术作业 a10-数控技术作业 为数控考查作业，含作业要求图片、Mastercam 加工模型（.mcam）、NC 程序、加工工序设置表格与考察作业报告。

  10. nanoFramework 学习 a11-nano.NET学习 为 nanoFramework 工程 led小灯点亮测试，目标板为 ESP32-S3；程序当前循环输出调试计数。

  11. 机器人学导论作业 a12-机器人学导论作业 含考查作业 Word、论文读书报告（轮式机器人机械结构与控制策略，ICTEST 2025），以及用 Python / MATLAB 复现 Pure Pursuit + PID、Stanley + PID、MPC 路径跟踪的仿真代码与结果图。另收 ICRA 2025 会议论文与参考论文 PDF、Robotics Toolbox 安装包。

  12. 机械制造技术课程设计 a13-机械制造技术课程设计 题目为 CA6140 车床拨叉零件的机械加工工艺规程及专用钻床夹具设计。材料为 HT200。现有零件图 / 毛坯图、拨叉工艺规程说明书、钻夹具体与装配图、完整版说明书，以及生成 Word / PDF / DXF 的辅助脚本。

  13. 桌面图标应用 a14-桌面图标应用 为 Windows 桌面图标升级器：C# / .NET 8 / WPF 工程 DesktopIconUpgrader，可扫描桌面与公共桌面的快捷方式、URL、文件夹和图标，生成多尺寸圆角 ICO，并在替换前保留可还原基线。含需求规格说明书、源码、冒烟测试与发布脚本。

  14. 钣金学习 a16-钣金学习 为 SolidWorks 钣金零件：a-钣金件1.SLDPRT、b-外壳钣金件.SLDPRT、b-散热钣金件1.SLDPRT。

  15. Minecraft 地形生成 a17-mc地形生成 用真实 Minecraft .mca 存档训练 2.5D 地形模型，输出高度场、生物群系与表层方块，并可拼接大图。含世界生成、region 解析、编码、训练、拼接与评估脚本，以及 dataset.npz、encoded.npz、输出样张。

  16. 小说 a18-小说 收录中长篇《焦岸》、压缩版 焦岸.md、《蔚蓝深渊航海记》，以及共享世界观资料库《沉默航线》（人物、地点、纪年、正典锚点等）。新作 中有扩展短篇《潮窗》。

  17. 形式场域论 根目录 a20-形式场域论.docx 为哲学文稿第一章，从海德格尔沉沦与布尔迪厄场域出发，讨论形式场域的三性结构、游戏原型、时间租金与元游戏姿态。

  18. 个人简历制作 z-个人简历制作 含陈煜暄（机制 231，宁波工程学院机械设计制造及其自动化）的简历 Markdown / HTML / PDF / Word、自我介绍稿，以及 机制231陈煜暄.pdf。
