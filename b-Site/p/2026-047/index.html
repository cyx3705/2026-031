Nomos

以 XY 为唯一空间真值的二维连续场地图引擎与模拟器，面向地图游戏和历史演化视频。

项目编号：2026-047。继承模板：0000-001-AIReady。当前阶段：V1.0 正式版规划；已有连续场地图、GIS 查看器、局部改界实验与跨采样轮廓重建。当前正在实现指令驱动的奥匈架空连续战线、分段视频直出；完整看海模拟和 B 站投稿尚未完成，当前不是 V1.0 正式版。

V1.0 目标为“选 meme 架空模板 → 自动演化 → 直出成片 → 点击投稿 B 站”。检查点、范围和验收统一见现行约定的 V1.0 计划，按 CP0–CP6 推进；先跑通 10 秒端到端样片，再完善演化规则、模板、稳定导出与投稿，最后进行候选版验收。

采用C++计算内核、TS前端和TS工作流宿主，验证连续场、拓扑约束、区域积分和确定性重放。当前使用 Web 壳查看背景场，可在 Codex 内置浏览器中拖动、连续缩放、换种子、调节小数细节层级和查询 XY。固定矩形区域的总量独立于显示层级；面板分别显示可见部分与未显示修正。

当前架构与开发入口

当前运行版本为 0.9.0（宿主 /health）；manifest中的 1.0.0 为目标正式版，尚未发布。

地图铺满窗口；点击左上角悬浮Nomos打开工作流控制面板。左下角常驻单栏地图工具，通过图层与显示、分形、视图与辅助栏目切换；底图及图层平铺为反色选择按钮，粗滑条内显示名称与数值，底部合并状态与比例尺，不设折叠。程序化、边界与交战实验参数仅在历史验收测试选择对应实验后显示。控制面板默认收起，页签行内关闭，空白处可拖动移动，四边和四角可调整长宽；含主界面、历史验收测试、数据显示、简介与说明书四页。地图工具属于TS前端，工作流面板页面属于宿主，经同源消息接口联动。面板随npm run build构建；版本保持0.9.0。

交战图层：首次准备运行python b-code-离线工具/Prepare-CombatCountries.py（复用现有Natural Earth原始数据，需项目既有shapely/pyshp）。开启左下交战图层后国家独立分色，点击本国再点击陆地邻国，即在共享边界启动基础交战并自动录制；右下提供结束录制、播放/暂停、时间与速度控制。结束录制下载当前地图视频（浏览器编码，默认WebM）；关闭图层会停止录制并退出交战。历史奥匈专用剧本仍在验收页，离线H.264导出保持原流程。

交战中点击右下“战线控制”：左键拖进攻箭头、右键拖防线，Esc退出恢复拖图。防线连续降低敌方推进速度，仍可突破；指令进入时间轴和JSON，粗箭头/防线逐渐暗淡。左侧底图与叠加层共用紧凑图标矩阵，悬停查看名称；“战线场”只显示综合吸引场，不再设子项。全欧洲场使用既有水文源4097×4097网格（约2.45公里格距）、单通道Float32，通过python b-code-离线工具/Prepare-EuropeFrontField.py准备；旧四通道生成物需重建。通用邻国交战共享此场，奥匈历史验收保留专用精细场。

真实区域数据

默认 Web 展示欧洲与地中海南岸：全域 8192² 高程（投影格距约 1.22 km）和阿尔卑斯／科西嘉沿岸约 76 m 格距重点数据。土地覆盖全域为独立 2048² 概览，阿尔卑斯／科西嘉另有与精细高程对齐的 2048² 数据。真实地图的高度/景观保留 WebGL2 GPU 三次 B 样条基底；国界与海岸另用源样本驱动的24级分形轮廓细化。重点区可在网页按钮中选择，原始数据、来源与哈希在 b-Data/EuropeMediterranean。

侧栏“细节显示精度”滑条支持 0.50–2.50× 连续调节，保留视野和所选图层，控制 GPU 输出分辨率与源窗口取样预算；不改变场函数或积分。地图右上角“现代国界”可独立开关，直接叠加于三个底图之上，不经过相图。采用 Natural Earth 5.1.0 的 1:1000万陆地边界，非实时边界服务，不含海上界线；争议及未定段按来源分类虚线显示。原始数据与来源位于 b-Data/ModernBorders，可用 python b-code-离线工具/Import-Borders.py 重建。

升级景观：python b-code-离线工具/Upgrade-Landscape.py；升级高程：python b-code-离线工具/Upgrade-DEM.py；重建旧概览：python b-code-离线工具/Import-GIS.py；启动服务后验证：python b-code-离线工具/Test-GIS.py。导入依赖 Python 3、numpy 与 Pillow，C++ 运行不依赖 Python。浏览器需支持 WebGL2。第三方数据保留各自许可和署名，不受本项目软件许可重新限制。当前已接入低于源分辨率的国界/海岸游戏轮廓细化；内陆高度与景观基底仍保持原定义。

德国—卢森堡连续边界实验

点击“德—卢边界实验”，查看局部统一函数 B(XY,t,c,s)。时间和空间尺度可调，函数将现代边界、县/市镇界、河流、DEM 推导分水岭及 1815/1900 粗略历史证据融合；不是在几张地图中切换。评分尚未校准为统计概率。已补下局部 z11 高程，约 76.437 投影米格距。

“执行首次重分割”固定两个原端点，重放 C++ 路径求解并核对离线验证的连续优化及两面分割结果。连续优化同时参考 1400 m / 350 m 的同一证据函数，减弱曲率惩罚，保留河道、行政界等证据带来的局部屈曲，不叠加随机锯齿。新旧边界、转移区域、节点面积可对照并恢复。此次是固定参数、可复现的有效预览，尚未实现自由端点移动及任意条件的实时几何提交。多边形积分采用数值求积及细化差异评估，不冒充既有矩形解析积分。

构建后用 b-code-离线工具/Prepare-Boundary.ps1 准备证据、求解和验证；运行服务后用 python b-code-离线工具/Test-Boundary.py 验收。原件、来源、缺口和事件在 b-Data/BoundaryExperiment。不是周边所有资料均已搜集：溪流保留于 OSM 原件，基线主要使用河流；分水岭为局部 DEM 推导，HydroBASINS 下载受限，历史源也非当地高精度资料。各数据保留其来源许可。

欧洲边界可能分布库

“边界可能分布”打开当前欧洲及地中海南岸视野中的统一 B(XY,t,c,s)；时间参数覆盖 1500–2100，14 个真实历史快照在函数内连续融合。接入 Natural Earth 国界/省级界/河流、GISCO NUTS3 与 HydroBASINS 相邻流域共享边。全域空间格距约 2.45 km，历史约 4.89 km，精度与覆盖不等于县级全覆盖；德卢精细实验独立保留。输出为未校准证据倾向。

按视野传输系数，WebGL2 计算热图；概览采用保留窄走廊的显示近似，放大后使用原生系数。源场和既有积分不随视图改变。原件、来源、许可、哈希及缺口在 b-Data/BoundaryLibrary；重建 python b-code-离线工具/Prepare-EuropeBoundary.py，运行服务后验收 python b-code-离线工具/Test-EuropeBoundary.py。

欧洲细证据升级：默认空间证据采用固定256投影米的系数场，按需从保留的真实矢量线生成并缓存。增加97857个域内LAU市镇源单元、geoBoundaries县/市镇、HydroRIVERS细河网及第12级流域，并将德卢细证据接入欧洲函数。原件、许可与数据量可在网页“欧洲证据、精度与来源”查看。地图来源精度仍各不相同，历史层仍为粗快照。重建 python b-code-离线工具/Upgrade-BoundaryEvidence.py，验收 python b-code-离线工具/Test-BoundaryEvidence.py；旧大陆格以 representation=legacy 保留。

国界与河流：现代国界已从Canvas描边改为可查询的连续水平集，零值为国界网络。新增独立河流开关、莱茵河入口与河岸/估算宽探针；河道以有宽度扫掠圆盘并集函数表示，GPU解析求值。宽度依据HydroRIVERS平均流量估算，不是实测；不随缩放改变。重建 python b-code-离线工具/Prepare-LineFields.py，验收 python b-code-离线工具/Test-LineFields.py；来源与模型见网页 /line-sources，长期定义见现行约定LINE-001至004。

源数据驱动的分形轮廓

默认开启“分形轮廓”，国界采用原始线段上的24级反对称小波，海岸采用高程邻域与坡度约束的独立海陆水平集。当前国界目标幅度为初版1.2倍（受拓扑净距约束），尺度衰减比0.64；父尺度与兄弟单元系数过于相似时，施加最高42%的局部幅度惩罚。海岸使用固定世界坐标索引的斜向小波，避免逐原始格重复相同形状。侧栏“曲折尺度”支持1–64倍连续调整（默认7），独立“波动强度”支持0–100%（默认70%）；国界根层大弯保留、细分拉宽，海岸波长按固定世界尺度调节。参考曲线保留邻界安全管；默认再施加全网共享的可逆连续形变，原始折点可以移动。放大后显露嵌套屈曲；缩小时按像素足迹连续过滤，完整XY函数不随相机改变，无外部随机种子。共享交点随同一映射移动，保持连接与原网络拓扑。侧栏“允许跨采样点”默认开启，关闭可对照此前固定折点的参考表示。细化结果为游戏几何，不是新测绘资料，也不是精确欧氏距离场。

点击“查看分形海岸细节”进入0.8647投影米/像素示例，可用“分形轮廓”对照原基底。GPU原生高程窗口启用海岸细化；远景降采样窗口是显示近似。源高度/景观矩形积分保持不变；海岸陆地面积不保证守恒，国界参考段的零有符号位移面积与全网形变的面积保持性质，均不能推出固定裁切区域或新省份加权资源积分不变。此前德卢重分割事务保持独立。

重建 python b-code-离线工具/Prepare-FractalContours.py，验收 python b-code-离线工具/Test-FractalContours.py。/coast-field、/line-field支持crossSamples=0/1（默认1）；/contour-sources列来源哈希及约束，/coast-field查询完整海陆函数；/line-field、/line-window国界默认使用分形表示，representation=legacy保留旧距离场。

架空奥地利 VS 匈牙利战线（网格求解、分形显示）

按当前用户决定，撤销原生连续分形运动模型。当前为321×217二维水平集网格，固定0.05秒步长并按速度作CFL子步；网格决定推进、归属、易手历史及2秒稳固。分水岭、河流、重要城市决定机动率，指令和事件决定局部压力，温度保留相持拉锯。合围、分裂和闭环消失通过二维符号场处理。244–280秒为声明式全面攻势，仍逐网格推进，不瞬时改写全境归属。

浏览器Worker求解并缓存每5秒状态，倒跳从最近缓存确定性重放。只从当前网格提取Marching Squares轮廓，再作共享世界坐标分形剪切显示；分形开关不修改求解、拓扑或历史。三层仍为完整/稳固/临时同阵营色、无分界描边。网格和20Hz步长有明确精度限制，显示细节不是新增军事数据精度。页面探针读取Worker当前已算时间，而非另一套解析公式；跳时期间画面可能短暂落后于时间滑条。
