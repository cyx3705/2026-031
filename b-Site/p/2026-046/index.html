Responsa

基于 NapCat 的独立 AI 客服机器人项目，从 HistoryFama 继承后精简重建。

当前保留 NapCat OneBot v11 HTTP 直连基础：配置连接、查询 QQ 登录身份、发送私聊和群聊纯文本。 消息接收、模型调用、知识库与自动回复待后续实现。

运行方式

需要 .NET 8 SDK，以及已登录 QQ、启用 OneBot v11 HTTP 服务的 NapCat。 这是独立控制台应用，无需 OneHistory 宿主、模块加载器或界面组件。

先查看帮助：

dotnet run --project ./b-Code/Responsa/Responsa.csproj -- --help

配置服务，地址与 token 使用你自己的 NapCat 配置：

dotnet run --project ./b-Code/Responsa/Responsa.csproj -- configure --baseurl http://127.0.0.1:3000 --token "<NapCat access token>"
dotnet run --project ./b-Code/Responsa/Responsa.csproj -- status

显式发送消息（会实际发到指定用户或群）：

dotnet run --project ./b-Code/Responsa/Responsa.csproj -- send --kind private --target 10001 --text "您好"
dotnet run --project ./b-Code/Responsa/Responsa.csproj -- send --kind group --target 10001 --text "您好"

端口和目标号码仅为格式示例。配置默认保存到当前用户应用数据目录下的 Responsa/napcat.json， Windows 通常为 %AppData%/Responsa/napcat.json。所有命令支持 --data-dir 指定其他目录。 省略 token 保留原值，显式空串清除；运行配置和凭据不入库。

构建与验收

dotnet build ./b-Code/Responsa/Responsa.csproj -c Release -p:NuGetAudit=false
dotnet run --project ./b-Code/Responsa.Tests/Responsa.Tests.csproj -c Release -p:NuGetAudit=false

离线验收使用 HTTP 替身，不连接真实 NapCat，不发送真实 QQ 消息。 本地生成普通应用文件可运行 dotnet publish，完整命令见项目清单的 package 字段；输出到 artifacts/Responsa。
