MessageHub

多平台消息收发聚合平台：每个平台一个「桥」，桥自带存储与统一 HTTP API，前端模块按同一套接口消费

项目内容

  • 目标：把多个平台的会话汇到一起统一收发。
  • 形态：没有第三方聚合后端。每个平台一个桥进程，桥自己落地 SQLite 并对外暴露同一套 HTTP API； 前端模块（HistoryVulcan 的 2026-037-HistoryFama）是这套 API 的消费方。
  • 部署方式：Docker Compose，跑在 WSL Ubuntu 的 Docker Engine 里，跑法与本机 Sub2API 一致。
平台 收 发
QQ ✅ 文字/@/图片，好友与群 ✅ 文字/附件
钉钉 ✅ 文字/文件/卡片/链接，单聊与群 ❌ 未打通（桥如实把 send 标成 false）
飞书 ✅ 文字/文件/图片/卡片/日程，单聊与群（网页版，不需要开放平台） ✅ 文字

快速开始

.\b-Deploy\Start.ps1          # 首次运行会生成 .env（随机密钥）、建数据目录，然后启动
.\b-Deploy\Start.ps1 -Status  # 查看容器状态
.\b-Deploy\Start.ps1 -Down    # 停止（数据保留）
.\b-Deploy\Start.ps1 -BridgeInfo   # 只打印各桥的地址与 token（填前端模块配置用）
