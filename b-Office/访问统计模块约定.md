# 访问统计模块

REQ-STATS-001：HistorySiteStats 由 ModuleReady 模板派生，接入 HistoryVulcan 8.x；页面走 Aurora，禁止内嵌浏览器或另造主题。

REQ-STATS-002：每次取数由 Windows OpenSSH 执行远端 curl，读取上海服务器 loopback 的 `/admin/api/stats`。不创建端口隧道，不启动常驻进程，不关闭宿主。严格校验已有主机指纹，非交互认证；30 秒超时终止本次子进程。并发取数合并，成功结果缓存 30 秒，失败不替换缓存；不将旧缓存作为新范围结果返回。

REQ-STATS-003：连接由本机设置命令保存到 `context.Environment.DataDirectory/connection.json`。只保存主机、用户和私钥路径，不复制私钥、不在仓库或包内保存机器配置。远端命令固定，日期范围只接受 7/14/30，不接受任意 shell 文本。

REQ-STATS-004：概览、每日明细、热门页面、访问来源、浏览器、最近访问均采用 Aurora table；每日明细代替原网页柱图，外观由宿主统一。时间按北京时间显示。接口空记录显示空表，取数失败由宿主提示并保留旧页面内容，刷新成功后才切换时间范围。

数据范围：上海日志和现存 visits.jsonl。迁到 GitHub Pages 后没有公网采集入口，新访问不进入上海日志；模块明确说明此限制，不把历史请求数称作全站当前访问量。

验证：`dotnet run --project b-Code/HistorySiteStats.Tests/HistorySiteStats.Tests.csproj -c Release`；submit 后还需活宿主核对与真实 SSH 取数。业务指令用 Diana 自描述查看 `sitestats` 域。
