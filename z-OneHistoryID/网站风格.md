# OneHistory 网站风格

> OneHistory 网站（`onehistory.exc0.top`）及其他 OneHistory 网页的唯一权威风格说明。颜色、字体、字标见 [README.md](README.md)。

- 实现：`2026-031-OneHistorySite/b-Site/`，包括 `assets/site.css`、`assets/site.js`、`index.template.html`、`p.template.html`。
- 本文件与实现冲突时，以本文件为准，并回头修实现。
- 新写 OneHistory 相关网页（工具页、说明页、Artifact 等）时，也按本文件执行。

---

## 1. 定位与原则

1. **目录站，内容来自 README。** 卡片和说明页都由各项目仓库的 README 生成，不手写内容；`index.html`、`p/**`、`projects.json` 是生成产物，不要手改。
2. **书页意象。** 首屏是两片摊开的书页加中缝，与字标里的书呼应。母题只出现在首屏，并保持低对比，不抢内容。
3. **深浅双主题，深色为默认。** 首帧前根据 `localStorage["oh-theme"]` 或系统偏好确定主题，避免闪白；右上角按钮切换并记住选择。
4. **暖色、低对比、主题色只做强调。** 大面积只用 `canvas` / `surface` 两层底色；金色只给链接、编号、选中态和很小的点缀（悬停时卡片左缘的书脊）。
5. **可分享的视图。** 搜索词和筛选写进地址栏（`?q=`、`?g=`），直接复制链接就能分享筛好的列表。
6. **少即是多。** 不加说明性的插画、徽章或渐变按钮。层级靠字号、字重和两层底色来表达。

## 2. 基础规格

### 2.1 排版

| 元素 | 规格 |
|---|---|
| 正文 | 17 px / 1.6，Noto Sans SC；手机上 16 px |
| 说明页正文 | 17.5 px / 1.75，最大宽度 76ch；手机上 16.5 px |
| 标题 | 字重 650，字距 -0.02 ~ -0.03em，行高 1.28 |
| 说明页 h1 / h2 / h3 / h4 | `clamp(28px,4.2vw,40px)` / `clamp(22px,2.5vw,27px)` / 20 px / 18 px |
| 卡片标题 | 19.5 px，字重 650；手机上 18.5 px |
| 编号 / 数字 | Outfit；编号 12.5 px、字距 0.05em、`accent` 色 |
| 次要文字 | `text-2`，14–15.5 px |

### 2.2 布局

- 容器统一用 `.wrap`：`max-width: 1200px`（屏宽 ≥ 1500 px 时为 1320），`margin-inline: auto`，左右内边距 `clamp(20px, 4vw, 48px)`。宽屏下内容居中，不贴左。
- 导航高 62 px（手机上 54 px），吸顶，背景为 `canvas` 86% 不透明度加 16 px 模糊；滚动后下缘出现 `hairline`。
- 断点：380 / 760 / 900 / 1100 / 1500 px。

### 2.3 形状与深度

| 元素 | 圆角 |
|---|---|
| 快捷键提示、行内代码 | 6 px |
| 小图标按钮、代码块、说明页图片、目录按钮 | 9–12 px |
| 搜索框 | 14 px |
| 卡片 | 16 px |
| 空状态框 | 18 px |
| 筛选片、分段控件、主要按钮 | 999 px（胶囊） |

- 边框统一 1 px `hairline`；强调时换成 `accent-soft`。
- 阴影只用 `shadow` 和 `shadow-lift` 两档。

### 2.4 图标

- 用内联 SVG，线条图标：`stroke-width` 1.6–1.8，圆头圆角，`fill: none`，颜色随 `currentColor`。
- GitHub 图标用填充形。
- 尺寸 16–22 px，放在 30–38 px 的点击区里。

## 3. 组件

### 3.1 导航

- 左侧是字标（高 26 px，手机上 22 px）；浅色主题用 `logo.png`，深色主题用 `logo-dark.png`，按 `data-theme` 二选一显示。
- 右侧是文字链接（15 px，`text-2`，悬停时变 `text` 色并出现 1.5 px `accent` 下划线），外加一个主题切换按钮（圆形 38 px）。
- 窄屏时逐级隐藏次要链接。

### 3.2 首屏

- 高度 `clamp(520px, 78svh, 860px)`，内容居中。
- 结构从上到下：
  1. 大字标：高 `clamp(58px, 9.2vw, 132px)`。
  2. 统计行：数字用 Outfit、`accent` 色，放大 1.18 倍；各项之间用 3 px 圆点分隔。
  3. 大搜索框：高 58 px，最大宽 560 px，带阴影，右侧显示 `/` 快捷键提示。
  4. 「项目库」下拉提示：带缓慢浮动的箭头。
- **书页母题**：
  - 两片页面：`surface` 渐隐底，`hairline-2` 边框，透明度 0.5，分别绕 Y 轴转 ±15°，外侧再叠两层页边。
  - 中缝：1 px `accent-soft` 渐隐竖线。
  - 背后一层 `accent-wash` 径向光晕。
  - 全部用 CSS 实现，`pointer-events: none`。
- 手机上隐藏两片书页，只保留中缝。

### 3.3 项目库工具条

- 吸附在导航下方，背景为 `canvas` 90% 不透明度加模糊。
- 从左到右：搜索框（高 44 px）、年份筛选片、排序分段控件。
- **筛选片**：胶囊，高 36 px。选中时 `accent-soft` 描边、`accent-wash` 底、字重 600；片内的计数用 Outfit、`accent` 色。
- **筛选项由编号推导**，不维护名单：
  - `YYYY-xxx` → 年份。
  - `0000-xxx` → 「模板」。
  - 其余 → 「其他」。
  - 排序为年份倒序在前，模板、其他垫后。
- 排序分段控件：`surface-2` 底，选中项为 `surface` 底加阴影。
- 手机上工具条折成两行：搜索和排序一行，筛选片单独一行并可横向滑动。

### 3.4 卡片

- 网格为 `repeat(auto-fill, minmax(268px, 1fr))`，间距 `clamp(12px, 1.3vw, 18px)`；手机上单列。
- 卡片：`surface` 底，1 px `hairline`，圆角 16，内边距 20/20/14，最小高度 172，带 `shadow`。
- 内容自上而下：编号（Outfit、`accent`）→ 名称 → 一句话描述（`text-2`，最多 3 行）→ 卡片脚（hairline 上边线，左边是相对时间或「外部仓库」标签，右边是 GitHub 按钮）。
- 整张卡片可点击，跳到说明页；卡片脚里的 GitHub 按钮单独可点。
- **悬停**：卡片上浮 3 px，改用 `shadow-lift`，描边变 `accent-soft`；左缘一条 2 px `accent` 书脊从中间展开。
- 相对时间写成「今天 / 昨天 / N 天前 / N 个月前 / N 年前」。
- 卡片描述最多 46 字，超出截断（`site.config.json` 的 `cardNoteMaxLength`）。

### 3.5 空状态与按钮

- **空状态**：1 px `hairline-2` 虚线框，圆角 18，居中写一行标题、一行说明，再放一个幽灵按钮。
- **幽灵按钮**：胶囊，高 40 px，`surface` 底，`hairline` 描边；悬停时描边变 `accent-soft`、底变 `surface-hover`。
- 圆形图标按钮：38 px，`surface` 底；悬停时图标变 `accent` 色。

### 3.6 说明页

- 顶部面包屑：`项目库 / 编号 名称`，编号用 Outfit、`accent`。
- 正文区最大 76ch。右侧目录栏宽 236 px，吸顶。
  - 目录自动取正文的 `h2` / `h3`，少于两条就隐藏目录栏，正文居中。
  - 屏宽 ≤ 1100 px 时，目录折叠成正文上方的一个「目录」按钮。
- 目录项左侧有 2 px 的线，当前章节高亮为 `accent` 色、字重 600；滚到页底时点亮最后一项。
- 正文元素：

| 元素 | 规格 |
|---|---|
| 链接 | 下划线，偏移 3 px，粗 1 px |
| 引用 | 左侧 3 px `accent` 竖线，文字 `text-2` |
| 表格 | 无竖线；表头为 `text-2` 小字，行间 `hairline`；宽表外套横向滚动容器 |
| 行内代码 | `code-bg` 底，1 px `hairline`，圆角 6 |
| 代码块 | `code-bg` 底，圆角 12，14 px |
| 图片 | 圆角 12，1 px `hairline` 描边 |
| 分隔线 | 1 px `hairline` |

- 正文里相对路径的图片一律改写到 `github.com/<仓库>/raw/HEAD/`（它会把 LFS 文件和普通文件分别重定向到正确的 CDN；直接用 `raw.githubusercontent.com` 时，LFS 图片只能拿到指针文本）。相对链接改写到仓库的 `blob/HEAD/` 页。
- 页尾放「← 返回项目库」和「GitHub 仓库 ↗」。

### 3.7 页脚

- 上方一条 hairline。
- 左侧写一句说明（首页写收录范围；说明页写「本页内容由某仓库的 README 自动生成」）。
- 右侧写构建时间、GitHub、exc0，各项之间用圆点分隔，14 px `text-2`。

## 4. 交互与动效

- 统一缓动为 `cubic-bezier(.22,.7,.3,1)`；悬停过渡 0.16–0.25 s。
- **首屏入场**：各元素依次上浮淡入（0.7 s，每项错开 80 ms）；两片书页从 ±58° 展开到 ±15°（1.3 s）。
- **滚动视差**：首屏内容随下滑后退并淡出，书页轻微放大。变量 `--sy`（0→1）由 `site.js` 写入。
- **卡片浮现**：进入视口时上浮淡入，按顺序错开 32 ms，最多错开 11 张。首屏已可见的卡片直接显示。
- **键盘操作**：
  - `/` 聚焦搜索框：在首屏时聚焦大搜索框，否则聚焦工具条搜索框。
  - `Esc` 清空搜索并失焦。
  - 在首屏搜索框里一开始打字，页面就自动滚到项目库。
- **减少动效**（`prefers-reduced-motion: reduce`）：温和降级，而不是全关。
  - 保留：入场淡入、书页展开（转角减半）、卡片淡入（错开间隔减半）。
  - 去掉：视差、循环浮动、位移和悬停上浮。

## 5. 可访问性

- 首行放「跳到项目库 / 跳到正文」跳转链接。
- 所有图标按钮都写 `aria-label`；装饰性 SVG 加 `aria-hidden`。
- 焦点样式为 `:focus-visible` 时显示 2 px `accent` 描边，偏移 3 px。
- 浅色主题的 `accent` 已压暗到 `#7F5E0F`，保证文字对比度过 AA。改色时要重新核对对比度。
- 加 `<meta name="color-scheme" content="dark light">`。

## 6. 与 Office 风格的关系

两者共用 README 中的字标、令牌和字体映射；取向不同：

| | 网站 | Office（见 [Office风格.md](Office风格.md)） |
|---|---|---|
| 主题 | 深浅双主题，深色默认 | 只用浅色 |
| 层级表达 | 两层底色、卡片、阴影、圆角 | 墨色实心条、粗细两级横线，无阴影无圆角 |
| 主题色 | 链接、编号、选中态、书脊 | 只给章节号 |
| 母题 | 首屏书页 | 字标加墨色条 |

网站里不要引入 Office 的墨色条和粗横线；Office 里也不要引入网站的卡片、阴影和圆角。

- `site.css` 顶部的注释写着「改这里要同步 2026-026 的 AuroraTokens.xaml」。现在的权威顺序是先改 README 再同步两者，下次改 `site.css` 时顺手更新这条注释。
