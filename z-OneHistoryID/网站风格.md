# OneHistory 网站风格

> OneHistory 网站（`onehistory.exc0.top`）及其他 OneHistory 网页的唯一权威风格说明。颜色、字体、字标见 [README.md](README.md)。

- 实现：`2026-031-OneHistorySite/b-Site/`，包括 `assets/site.css`、`assets/site.js`、`index.template.html`、`p.template.html`。
- 本文件与实现冲突时，以本文件为准，并回头修实现。
- 新写 OneHistory 相关网页（工具页、说明页、Artifact 等）时，也按本文件执行。
- 2026-09-28 起，网站改为 [Office风格.md](Office风格.md) 的屏幕版：**文艺工业风**。取折中：Office 的高对比模块（墨色条、墨色选中块、粗细两级墨线）是最重要的风格，必须保留；屏幕上的圆角也保留。两者的分工是**块用圆角，线用直线**（§2.3）。

---

## 1. 定位与原则

1. **目录站，内容来自 README。** 卡片和说明页都由各项目仓库的 README 生成，不手写内容；`index.html`、`p/**`、`projects.json` 是生成产物，不要手改。
2. **与 Office 同一套语言。** 「重量」只来自墨色块和粗横线：段标题接墨色条，信息用图纸标题栏式的横线分格，表格白底加粗细两级横线。
3. **书页意象。** 首屏是两片摊开的书页加中缝，与字标里的书呼应。母题只出现在首屏，并保持低对比，不抢内容。
4. **深浅双主题。** 首帧前根据 `localStorage["oh-theme"]` 或系统偏好确定主题，避免闪白；右上角按钮切换并记住选择。深色主题里「墨色」就是米色正文色，墨色条随之变成米色条，关系不变。
5. **金色只做编号。** `accent` 用于项目编号、章节号、统计数字、筛选计数，以及正文链接的下划线。链接文字本身用墨色，悬停才变金。
6. **少即是多。** 不加投影、渐变按钮和灰底卡片，也不加说明性的插画和徽章。卡片只有一圈细边，重量交给里面的墨线。
7. **可分享的视图。** 搜索词和筛选写进地址栏（`?q=`、`?g=`），直接复制链接就能分享筛好的列表。

## 2. 基础规格

### 2.1 排版

| 元素 | 规格 |
|---|---|
| 正文 | 17 px / 1.6，Noto Sans SC；手机上 16 px |
| 说明页正文 | 17.5 px / 1.75，最大宽度 76ch；手机上 16.5 px |
| 标题 | 字重 650，字距 -0.02 ~ -0.03em，行高 1.3 |
| 说明页 h1 / h2 / h3 / h4 | `clamp(30px,4.4vw,42px)` / `clamp(20px,2.2vw,24px)` / 19 px / 17.5 px |
| 卡片标题 | 19.5 px，字重 650；手机上 18.5 px |
| 编号 / 数字 | Outfit（缺失时 Bahnschrift）；编号 13 px、字重 600、字距 0.05em、`accent` 色 |
| 次要文字 | `text-2`，12–15.5 px |
| 代码 | Consolas |

### 2.2 布局

- 容器统一用 `.wrap`：`max-width: 1200px`（屏宽 ≥ 1500 px 时为 1320），`margin-inline: auto`，左右内边距 `clamp(20px, 4vw, 48px)`。
- 导航高 62 px（手机上 54 px），吸顶，背景为 `canvas` 90% 不透明度加 16 px 模糊；滚动后下缘出现 `hairline-2`。
- 断点：380 / 760 / 900 / 1100 / 1500 px。

### 2.3 形状、线与块

**块用圆角，线用直线。** 这是 Office 高对比模块与屏幕圆角共存的办法：

- **块**（有面积的东西）一律圆角：卡片、输入框、按钮、筛选片、代码块、图片、墨色条、墨色选中块。
- **线**（只有长度的东西）保持 Office 的直线：表格线、页尾线、目录线、卡片里编号后的墨线。线没有角，所以两套语言不会在同一个元素上打架。
- 不要把粗墨线画在圆角块的边上（例如圆角卡片的 `border-top` 加粗）：线会顺着圆角弯下去，两边都不像。要强调一个圆角块，就把整圈细边换成墨色，或在块里放一道墨线。
- **不用投影。** 层级靠墨色块、墨线和 `surface` 一层底色表达。

| 圆角令牌 | 值 | 用在 |
|---|---|---|
| `r-card` | 16 px | 卡片、空状态框 |
| `r-ctl` | 10 px（大搜索框 14 px） | 输入框、按钮、图标按钮、代码块、目录按钮；图片 12 px |
| `r-bar` | 7 px | 墨色条、筛选片 |
| `r-sm` | 5 px | 行内代码、快捷键提示、小标签、焦点框 |

- 线的三档：

| 线 | 规格 | 用在 |
|---|---|---|
| 粗墨线 | 2 px `ink` | 表格、目录、页尾的**开头**；卡片编号后的墨线 |
| 细墨线 | 1 px `ink` | 表头下方、表格的**收口**；需要强调的圆角块的整圈边（首屏标题栏、悬停的卡片） |
| 细线 | 1 px `hairline-2` | 行间、格间竖线、卡片脚；圆角块的边 |

- **墨色条**：段标题后接一段实心 `ink` 条（圆角 `r-bar`），高度等于标题行高，一直延伸到右缘；条里可以反白写一句说明（13 px，`on-ink` 色，右对齐）。
- **墨色块预算**：每屏最多一个大墨色块。小的选中态（筛选片、悬停的图标按钮）不算。

### 2.4 墨色与反白令牌

`site.css` 在 README 令牌之外只加以下别名，不引入新颜色：

| 别名 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `ink` | = 浅色 `text` | = 深色 `text` | 墨色条、粗细墨线、选中块 |
| `on-ink` | = 浅色 `canvas` | = 深色 `canvas` | 墨色块上的反白字 |
| `accent-on-ink` | = 深色 `accent` | = 浅色 `accent` | 墨色块上的编号、计数（同 Office 的 accent-dark） |
| `text-2-on-ink` | = 深色 `text-2` | = 浅色 `text-2` | 墨色块上的次要文字 |

### 2.5 图标

- 用内联 SVG，线条图标：`stroke-width` 1.6–1.8，圆头圆角，`fill: none`，颜色随 `currentColor`。
- GitHub 图标用填充形。
- 尺寸 16–22 px，放在 30–38 px 的圆角方形点击区里。

## 3. 组件

### 3.1 导航

- 左侧是字标（高 26 px，手机上 22 px）；浅色主题用 `logo.png`，深色主题用 `logo-dark.png`，按 `data-theme` 二选一显示。
- 右侧是文字链接（15 px，`text-2`，悬停时变 `text` 色并出现 2 px `ink` 下划线），外加一个主题切换按钮（38 px 圆角方块，`hairline-2` 边；悬停时整块填墨）。
- 窄屏时逐级隐藏次要链接。

### 3.2 首屏

- 高度 `clamp(520px, 78svh, 860px)`，内容居中。
- 结构从上到下：
  1. 大字标：高 `clamp(58px, 9.2vw, 132px)`。
  2. **标题栏**（取自 Office 封面信息栏）：最大宽 560 px，圆角 14，整圈 1 px `ink` 边，`canvas` 底（挡住后面的书脊线），三格「公开项目 / 最近更新 / GitHub」，格间 `hairline-2` 竖线，宽度比 1 : 1 : 1.7。它有底色，属于「块」，所以用圆角加墨色边，而不是 Office 的粗细横线。标签 12 px `text-2`，值 15 px 粗体；项目数用 Outfit、`accent`、18 px。手机上折成两行，GitHub 独占第二行。
  3. 大搜索框：高 56 px，最大宽 560 px，圆角 14，`surface` 底、`hairline-2` 边；聚焦时底色回到 `canvas`、边线变 `ink`。右侧显示 `/` 快捷键提示。
  - 标题栏与搜索框同宽同圆角，上下相距 12 px，配成一对：上面墨色边（高对比），下面 `hairline-2` 边加 `surface` 底（可输入）。
  4. 「项目库」下拉提示：带缓慢浮动的箭头。
- **书页母题**：
  - 两片页面：`surface` 渐隐底，`hairline-2` 边框，外侧圆角 8、书脊侧 2，透明度 0.5，分别绕 Y 轴转 ±15°，外侧再叠两层页边。
  - 中缝：1 px `hairline-2` 渐隐竖线。
  - 不加光晕。全部用 CSS 实现，`pointer-events: none`。
- 手机上隐藏两片书页，只保留中缝。

### 3.3 项目库工具条

- 吸附在导航下方，背景为 `canvas` 94% 不透明度加模糊。
- 从左到右：搜索框（高 40 px）、年份筛选、排序。
- **筛选**：一排圆角片，高 36 px，间距 6 px，`hairline-2` 边。选中的一片填 `ink`、字为 `on-ink`、字重 600，格内计数为 `accent-on-ink`；未选中的计数为 `text-2`。
- **筛选项由编号推导**，不维护名单：
  - `YYYY-xxx` → 年份。
  - `0000-xxx` → 「模板」。
  - 其余 → 「其他」。
  - 排序为年份倒序在前，模板、其他垫后。
- **排序**：两个文字按钮，选中项为 `text` 色、字重 600，下方 2 px `ink` 线。
- 手机上工具条折成两行：搜索和排序一行，筛选单独一行并可横向滑动。

### 3.4 段标题与卡片

- 卡片网格上方是段标题「项目库」，后接墨色条，条里反白写「共 N 个项目」或「匹配 M / N 个项目」。这是首页唯一的大墨色块。
- 网格为 `repeat(auto-fill, minmax(268px, 1fr))`，间距 `clamp(12px, 1.3vw, 18px)`；手机上单列。
- **卡片是圆角块**：圆角 16，1 px `hairline-2` 边，无底色、无投影；内边距 16/18/12。
- 内容自上而下：**编号 + 墨线**（编号 Outfit、`accent`，后接一道 2 px `ink` 线延伸到右边距，即 Office「章节号 + 墨色条」的缩小版）→ 名称 → 一句话描述（`text-2`，最多 3 行）→ 卡片脚（`hairline-2` 上边线，左边是相对时间或「外部仓库」小标签，右边是 GitHub 按钮）。
- 整张卡片可点击，跳到说明页；卡片脚里的 GitHub 按钮单独可点（悬停时整块填墨）。
- **悬停**：外框从 `hairline-2` 变成 `ink`，编号后的墨线加粗到 8 px（0.24 s）。不上浮、不加投影。
- 相对时间写成「今天 / 昨天 / N 天前 / N 个月前 / N 年前」。
- 卡片描述最多 46 字，超出截断（`site.config.json` 的 `cardNoteMaxLength`）。

### 3.5 空状态与按钮

- **空状态**：1 px `hairline-2` 实线框，圆角 16，居中写一行标题、一行说明，再放一个按钮。
- **按钮**：高 40 px，圆角 10，1 px `ink` 边，透明底；悬停时整块填墨、字变 `on-ink`。
- 图标按钮：38 px，圆角 10，`hairline-2` 边；悬停时整块填墨。

### 3.6 说明页

- 顶部面包屑：`项目库 / 编号 名称`，编号用 Outfit、`accent`。
- 正文区最大 76ch。右侧目录栏宽 236 px，吸顶。
  - 目录自动取正文的 `h2` / `h3`，少于两条就隐藏目录栏，正文居中。
  - 屏宽 ≤ 1100 px 时，目录折叠成正文上方的一个「目录」按钮（圆角 10）。
- 目录：「目录」二字下方一道粗墨线；各项左侧留 2 px 位，当前章节为 `text` 色、字重 600、左侧 2 px `ink` 线；一级项前带编号（Outfit、`accent`）。滚到页底时点亮最后一项。
- 正文元素：

| 元素 | 规格 |
|---|---|
| h1 | 项目名称；紧跟的引用（README 的 `> 一句话`）当副标题：18.5 px `text-2`，不加竖线 |
| h2 | **Office 标题 1**：编号 `01`（Outfit、`accent`）+ 文字 + 墨色条（圆角 `r-bar`）。编号由 `site.js` 按顺序补上；README 自带的「1. 」「2、」挪进编号位，不重复显示 |
| h3 / h4 | 只有文字，不加线 |
| 链接 | 墨色文字，1 px `accent-soft` 下划线，偏移 3 px；悬停时文字变金、下划线变实 |
| 引用 | 左侧 3 px `ink` 竖线，文字墨色（正文里唯一允许的线，且是竖线） |
| 表格 | 白底（同页面底色）；顶部 2 px `ink`，表头下 1 px `ink`，行间 `hairline-2`，末行 1 px `ink` 收口；表头为 13.5 px 粗体墨色；不画竖线；宽表外套横向滚动容器 |
| 无序列表 | 6 px 墨色小方块（同 Office 的 `■`，圆角 1.5） |
| 有序列表 | 编号用 Outfit 粗体 |
| 行内代码 | `code-bg` 底，无边框，圆角 5 |
| 代码块 | `code-bg` 底，无边框，圆角 10，14 px |
| 图片 | 圆角 12，1 px `hairline-2` 描边 |
| 分隔线 | 1 px `hairline-2` |

- 正文里相对路径的图片一律改写到 `github.com/<仓库>/raw/HEAD/`（它会把 LFS 文件和普通文件分别重定向到正确的 CDN；直接用 `raw.githubusercontent.com` 时，LFS 图片只能拿到指针文本）。相对链接改写到仓库的 `blob/HEAD/` 页。
- 页尾一道粗墨线，下面放「← 返回项目库」和「GitHub 仓库 ↗」。

### 3.7 页脚

- 上方一条 `hairline-2`。
- 左侧写一句说明（首页写收录范围；说明页写「本页内容由某仓库的 README 自动生成」）。
- 右侧写构建时间、GitHub、exc0，各项之间用圆点分隔，14 px `text-2`；链接带 `hairline-2` 下划线。

## 4. 交互与动效

- 统一缓动为 `cubic-bezier(.22,.7,.3,1)`；悬停过渡 0.16–0.28 s。
- **首屏入场**：各元素依次上浮淡入（0.7 s，每项错开 80 ms）；两片书页从 ±58° 展开到 ±15°（1.3 s）。
- **滚动视差**：首屏内容随下滑后退并淡出，书页轻微放大。变量 `--sy`（0→1）由 `site.js` 写入。
- **卡片浮现**：进入视口时上浮淡入，按顺序错开 32 ms，最多错开 11 张。首屏已可见的卡片直接显示。
- **键盘操作**：
  - `/` 聚焦搜索框：在首屏时聚焦大搜索框，否则聚焦工具条搜索框。
  - `Esc` 清空搜索并失焦。
  - 在首屏搜索框里一开始打字，页面就自动滚到项目库。
- **减少动效**（`prefers-reduced-motion: reduce`）：温和降级，而不是全关。
  - 保留：入场淡入、书页展开（转角减半）、卡片淡入（错开间隔减半）。
  - 去掉：视差、循环浮动、位移；卡片悬停的墨色条直接出现，不再铺开。

## 5. 可访问性

- 首行放「跳到项目库 / 跳到正文」跳转链接。
- 所有图标按钮都写 `aria-label`；装饰性 SVG 加 `aria-hidden`。
- 焦点样式为 `:focus-visible` 时显示 2 px `accent` 描边，偏移 3 px。
- 浅色主题的 `accent` 已压暗到 `#7F5E0F`，保证文字对比度过 AA。改色时要重新核对对比度，包括墨色块上的 `accent-on-ink`。
- 加 `<meta name="color-scheme" content="dark light">`。

## 6. 与 Office 风格的关系

网站是 Office 风格的屏幕版，共用 README 中的字标、令牌和字体映射。差别只来自介质：

| | 网站 | Office（见 [Office风格.md](Office风格.md)） |
|---|---|---|
| 主题 | 深浅双主题 | 只用浅色 |
| 层级表达 | 墨色条、粗细两级横线，另有 `surface` 一层底色给悬停和输入框 | 墨色条、粗细两级横线 |
| 圆角 | 块用圆角、线用直线 | 同一规则；墨色块一律用圆角形状画 |
| 投影 | 不用 | 不用 |
| 主题色 | 编号、章节号、统计数字；链接下划线 | 章节号、Excel 合计值 |
| 母题 | 首屏书页 + 标题栏 | 字标加墨色条 |
| 数字字体 | Outfit（Bahnschrift 兜底） | Bahnschrift |

网站独有、Office 里不要用的：悬停态、圆角块、书页母题。

## 7. 待定与偏差

- **介绍动画的纸本版**（`b-Code/intro/intro-paper.js`）有一套独立配色：纸 `#F5F0E8`、墨 `#1F1D1A`、金 `rgb(168,122,18)`，外加专属 Claude 批注的陶土红 `rgb(217,119,87)`。
  - 代码注释说这个金是「站点浅色主题的 --accent」，但站点浅色的 `accent` 现在是 `#7F5E0F`。注释已经过期。
  - 需要决定：纸本版是否另立一套「动画纸本令牌」写进 README，还是改回共用令牌。在此之前不要把这套颜色用到别处。
- **HistoryAurora**（1.28.0 起跟进，Aurora 仓 REQ-UI-132 / 133、DEC-049）：圆角（页面 20、组件 8）保留；链接列墨色字、悬停变金；
  选中态（表格行、列表、右栏当前场景、开关、主按钮）是墨色块反白；段标题接墨色条（`AuroraSectionHeading`）；强调节点整圈墨色边。
  与网站不同的三处，都是用户定的：
  - **表头是反色圆角块**（墨底反白字），不用粗细墨线——程序里表头是一整条控件，线看起来太突兀。
  - **工具条、控制台筛选条保留 `surface-2` 底**：Aurora 的层级是「底部 → 页面 → 控制面板」三层色台阶，不照搬「卡片不填底色」。
  - **深色底色与 README 不同**：Aurora 深色 canvas `#1A1D1C`、surface-2 `#242625`（README 为 `#121414` / `#191C1B`），是 Aurora 自己的台阶方向。
    要统一时先定以哪边为准，再改 README 或 `AuroraTokens.Dark.xaml`。
