# OneHistoryID

> OneHistory 视觉识别的唯一权威处：品牌基础写在本文件，各介质的风格各写一份，其他仓库只写引用。

## 1. 权威关系

| 内容 | 权威文件 | 实现（跟随权威） |
|---|---|---|
| 字标、颜色令牌、字体 | 本文件 | `b-Site/assets/site.css`、HistoryAurora `AuroraTokens.xaml`、各 Office 模板 |
| 网站风格 | [网站风格.md](网站风格.md) | `b-Site/`（模板、样式、脚本） |
| Office 风格 | [Office风格.md](Office风格.md) | `0000-000-Template/z-Unused/b-Office/` |

- 改色的顺序：先改本文件，再同步 `site.css` 和 `AuroraTokens.xaml`，最后同步 Office 模板。
- 实现与本目录冲突时，以本目录为准，并回头修实现。
- 其他仓库需要说明风格时，只放一个指向本目录的引用文件（例如 `b-Office/风格.md`），不要复制规则。

## 3. 颜色令牌

两套主题共用同一组令牌名。

- **深浅两套分开设定**（2026-10-24 起）：不拿一套主题的颜色去当另一套的颜色。2026-10-23 试过反色对齐（条带 = 另一套主题的墨色块），
  无论怎么调，总有一种颜色在某一套主题里显得突兀，已退回。改色时两套各自调、各自看。
- **文字只有一种颜色**：浅色 `#38352F`、深色 `#DAD7CE`。正文、标题、次要文字都是它；`text-2` 保留名字，值与 `text` 相同。
  这一档由用户从七档样张里选定：对背景约 11:1，比原来的墨色（`#26231E`）柔和，比原来的次要文字（`#6A6458`）清楚。
- 墨色块（`ink`）、页面（`surface`）、条带（`surface-2`）用原值，墨色块不再等于文字色；墨色块上的反白字是本主题的底色（`canvas`）。
- **主题色深浅共用一个值**（2026-11-05 起）：金 `#A97F22`，墨色块上的编号、计数也直接用它（原 `accent-on-ink` 别名已删除）。
  原来浅色 `#7F5E0F`、深色 `#D9A441` 两套，墨块上又反过来用，记不住，已统一。这一档由用户从五档金色样张（`#997224` → `#D6A73A`）里选定：
  对浅色 `canvas` 3.5 : 1、深色 `canvas` 5.1 : 1，对浅色墨块 4.3 : 1、深色米白墨块 2.6 : 1。
  金色只做粗体编号和数字，正文文字不用它，所以不按正文的 AA（4.5 : 1）要求。深色米白墨块上偏淡，是保留米白墨块的代价。
- 层级是「底色 → 卡片 → 条带」三层小台阶，浅色越往上越深，深色与之对应。

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `canvas` | `#FBFAF7` | `#121414` | 页面底色；墨色块上的反白字 |
| `surface` | `#F3F1EC` | `#1D201F` | 卡片、输入框、按钮底 |
| `surface-2` | `#EBE9E4` | `#191C1B` | 条带、分段控件底、快捷键提示 |
| `surface-hover` | `#E5E3DE` | `#2A2D2C` | 悬停底色 |
| `text` | `#38352F` | `#DAD7CE` | 正文、标题 |
| `text-2` | `#38352F` | `#DAD7CE` | 次要文字、标签、说明（与 `text` 同值） |
| `ink` | `#26231E` | `#E2DAC6` | 墨色条、粗细墨线、选中块（Office 里称 ink） |
| `accent` | `#A97F22` | `#A97F22` | 主题色：链接、编号、选中态、章节号（深浅同值） |
| `accent-soft` | `rgba(169,127,34,.42)` | `rgba(169,127,34,.42)` | 选中 / 悬停时的描边 |
| `accent-wash` | `rgba(169,127,34,.10)` | `rgba(169,127,34,.10)` | 选中底、首屏光晕 |
| `hairline` | `#E5E3DE` | `#2A2D2C` | 常规分隔线、卡片边框 |
| `hairline-2` | `#D5D1C8` | `#343736` | 较深的分隔线、虚线框 |
| `code-bg` | `#EBE9E4` | `#171A19` | 代码底色 |
| `shadow` | `0 10px 30px rgba(38,35,30,.06)` | `0 16px 40px rgba(0,0,0,.26)` | 只给浮在上面的弹层（网站与 Office 都不用） |
| `shadow-lift` | `0 16px 38px rgba(38,35,30,.12)` | `0 22px 52px rgba(0,0,0,.40)` | 同上，较高的弹层 |
| `ring` | `0 0 0 4px rgba(169,127,34,.16)` | `0 0 0 4px rgba(169,127,34,.18)` | 暂不使用（网站聚焦改为边线变墨色） |

- 主题色只用来强调，不做大面积底色。
- 「墨色」（`ink`）：墨色条、粗细墨线、选中块都用它，比正文略深。墨色块上的反白字是本主题 `canvas`，其余见 [网站风格.md §2.4](网站风格.md)。
- 不要引入令牌以外的颜色。

## 4. 字体

整套用衬线体（2026-11-02 起）：中文宋体，西文与数字按国标公文惯例用罗马体 Times New Roman。宋体呼应衬线字标与书页母题。

| 用途 | 网站 | Office | 说明 |
|---|---|---|---|
| 中文（标题与正文） | Noto Serif SC（思源宋体） | 宋体（SimSun） | Office 里可变字体不可靠、发给别人也可能缺字体，故用系统自带的宋体 |
| 西文（标题与正文） | Times New Roman → Tinos | Times New Roman | Tinos 与 Times New Roman 度量一致，给没有 TNR 的 Android / Linux 兜底 |
| 数字、编号、英文标签 | Times New Roman → Tinos | Times New Roman | 同上；不再用几何体 |
| 行内代码（路径、文件名） | 同正文罗马体，靠 `code` 底色区分 | — | |
| 多行代码块 | Consolas → 等宽 | Consolas | 唯一保留等宽的地方，缩进要对齐 |

- 网站字体经 Google Fonts 加载：Noto Serif SC 400 / 500 / 600 / 700，Tinos 400 / 700 / 400 斜体。字体栈写作 `"Times New Roman", Tinos, "Noto Serif SC", …`：罗马体在前，西文和数字取罗马体，中文落到宋体。
- 罗马体的数字比几何体矮，同字号显小：网站上编号、页码等数字比原先大 1–1.5 px。
- 标题不再收紧字距（衬线体收紧会挤），字重 700。
- 宋体横画细：网站深色主题正文字重 500；Office 只用浅色，不需要。
