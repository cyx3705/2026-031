# OneHistory Office 风格

> Word / PowerPoint / Excel 模板的唯一权威风格说明。字标、颜色令牌、字体的定义见 [README.md](README.md)；各仓库里的 Office 模板只写引用，不复制本文内容。

- 适用范围：OneHistory 体系内所有新写或改写的 Office 模板（报告、表单、演示、清单）。
- 风格名：**浅色 · 文艺工业风**。暖白纸色、衬线字标带来「文艺」；墨色实心块、粗细两级横线、等宽感数字带来「工业」。
- 参考实现：`0000-000-Template/Unused/b-Office/` 下的四个文件（见文末「参考实现」）。
- 本文件与参考实现冲突时，以本文件为准，并回头修参考实现。

---

## 1. 核心规则（先读这一节）

1. **大段落用墨色条隔开，小段落不分。** 一级标题右侧接一段墨色实心条，一直延伸到右边距；二级标题只有文字，不加任何线。
2. **标题最多两级。** 需要再往下分的内容直接写进正文，或者改用表格。
3. **横线只出现在表格里。** 正文里不用段落边框做分隔，标题上下也不加线。
4. **表头白底，用粗横线。** 表头行白底，顶部一道墨色粗线，表头下方一道细墨线；数据行之间用浅细线；最后一行用细墨线收口。不画竖线。
5. **暗金只给章节号。** 金色只出现在一级标题的编号或字母上（以及 Excel 的合计值），其余一律用墨色和灰色。
6. **少放细碎装饰。** 不用英文眉题、装饰短线、灰底卡片、描边框。页面上的「重量」只来自墨色块和粗横线。
7. **黑块预算：有内容以后，每页最多一个大墨色块。** 模板空着时显得黑块多是正常的，不要为此改掉墨色条。PPT 内容页的标题墨色条已占掉这一块，页内其他需要强调的块改用墨色边框，不再整块填墨。
8. **块用圆角，线用直线**（与 [网站风格.md §2.3](网站风格.md) 同一条规则）。有面积的块（墨色条、甘特条、节点、图片占位框、流程块）在介质允许时用圆角；只有长度的线（表格线、块顶粗线、信息栏线）一律直线。不要把粗墨线画在圆角块的边上。
   - 三种文件都照此执行：墨色块一律用**圆角矩形形状**来画，不用文字底纹、单元格填色。
   - 圆角：PPT 墨色条 0.09 in、小块与甘特条 0.06 in、大块与占位框 0.16 in；Word 墨色条 5.5 pt、图片占位 11 pt；Excel 墨色条 5.5 pt。
   - Word 的具体做法见 §4.4 与 §8.2。

## 2. 颜色

色值的唯一定义在 [README.md §3](README.md)。Office 只用浅色主题的令牌，外加两个深色令牌用于墨色背景；各令牌在 Office 里的用途如下。

| 本文称呼 | README 令牌 | Office 里的用途 |
|---|---|---|
| canvas | 浅色 `canvas` | 页面底色（Word 页面颜色、PPT 浅色页背景）；墨色块上的反白文字 |
| ink（墨色） | 浅色 `text` | 正文、标题、墨色条、表格粗线、PPT 章节页背景 |
| text-2 | 浅色 `text-2` | 次要文字：填写提示、标签、题注、占位符 `〔〕` |
| accent | 浅色 `accent` | **只用于**浅色背景上的章节号或分节字母，以及 Excel 合计值 |
| accent-dark | 深色 `accent` | **只用于**墨色背景上的章节号（PPT 章节页） |
| text-2-dark | 深色 `text-2` | 墨色背景上的次要文字 |
| hairline | 浅色 `hairline` | 极浅分隔（如甘特图网格） |
| hairline-2 | 浅色 `hairline-2` | 表格行间细线、标题栏内部分隔、图片占位框 |
| code | 浅色 `code-bg` | 代码块底色 |

- 不要使用令牌以外的颜色。
- 不要用纯黑 `#000000`，墨色一律用浅色 `text`。

## 3. 字体

按 [README.md §4](README.md) 的 Office 一列执行：

- 中文用 **Microsoft YaHei**（微软雅黑）。
- 西文正文用 **Segoe UI**。
- 数字、编号、英文标签、页码用 **Bahnschrift**。
- 代码用 **Consolas**。

- 禁止出现 **等线（DengXian）**。见 §8.1：Word 保存时会把中文字体偷换成主题字体，必须同时修改主题。
- 验收时导出 PDF，检查字体列表里没有 DengXian。

## 4. Word

### 4.1 页面

- A4，左右边距 2.5 cm（1417 twips），上 1500 twips，下 1300 twips，页眉距 720 twips，页脚距 640 twips。
- 页面颜色设为 canvas（`w:background` + `displayBackgroundShape`）。打印时默认不出底色，这是预期行为。
- 正文 10.5 pt，行距约 1.33–1.4 倍（`w:line` 320–330，auto），段后 6–7 pt。雅黑本身行高偏大，不要超过 1.4 倍。

### 4.2 封面 / 首页

- **顶栏**：一张无边框的两列表格，行高固定 675 twips。左格放墨色字标（`assets/logo-ink.png`，150×45 px，格宽 2442 twips）；右格里放一个与单元格同大的圆角墨色形状（「在单元格中版式」），一直到右边距。
- **英文标签**：Bahnschrift 10–11 pt 粗体，字距加宽，墨色。例如 `RESEARCH REPORT`、`PROJECT PROPOSAL`。
- **标题**：报告类 32 pt 粗体；表单类 22 pt 粗体。
- **副标题**：一句话说明，13 pt，text-2，不加竖线。
- **信息栏（图纸标题栏式）**：表格顶部 2.25 pt 墨色粗线，底部 1 pt 墨线，内部 hairline-2 分隔。标签 8 pt text-2，值 10–11 pt 粗体；占位值用 text-2。
- 封面不放页眉页脚（首页不同）。报告类封面单独成页；表单类首页直接接正文。

### 4.3 页眉页脚

- **页眉**：左侧墨色字标，80×24 px；右侧文档名或主题，8.5 pt，text-2。不加横线。
- **页脚**：左侧项目编号或英文文档名，Bahnschrift 7.5–8.5 pt，text-2；右侧页码，Bahnschrift 10 pt 粗体，墨色。不加横线。

### 4.4 标题

| 级别 | 样式 | 规格 |
|---|---|---|
| 一级（报告类） | 标题 1 | 17 pt 粗体；编号 `01` 为 Bahnschrift、accent；标题后接墨色条；段前 32 pt、段后 12 pt |
| 一级（无编号） | 标题 1（无编号） | 同上，但不带编号。用于摘要、参考资料、附录 |
| 一级（前置页） | 墨条标题 | 同为 17 pt，带墨色条，但**不进目录**。用于修订记录、审阅与分发、目录 |
| 一级（表单类） | 表单分节 | 13 pt 粗体；字母 `A B C…` 为 Bahnschrift、accent；标题后接墨色条 |
| 二级 | 标题 2 | 13.5 pt 粗体；编号 `1.1` 为 Bahnschrift、墨色；不加线 |

- 同一份文档里，所有一级标题（包括墨条标题）必须同字号、同字体。
- **墨色条**：标题后面接一个**嵌入型圆角墨色形状**，高约为标题字号的 1.24 倍（17 pt 标题 → 21 pt），下沉到与汉字字身居中，长度一直到右边距。实现方式见 §8.2。
  - 标题文字与墨色条是两个段落，中间用**样式分隔符**连成一行：标题段落进目录，墨色条所在的「墨色条」段不进目录，所以目录里不会出现黑条。
  - 可以把一句说明反白写在条里：8.5 pt，canvas 色，右对齐。说明写在形状里，不会进目录。
  - **新加标题**：复制一个现有标题连同它后面的墨色条，再改字。
  - **改了标题文字**：墨色条长度不会自动伸缩。标题改长后条会被挤到下一行，把条拖短即可；改短了就把条拉长到右边距。
- 编号用多级列表并挂到样式上：一级为 `0%1`，显示 `01`；二级为 `%1.%2`，显示 `1.1`。这样对任意段落套「标题 1 / 2」都会自动编号。
  - 限制：超过 9 章时会显示成 `010`。
- 目录只收录 1–2 级。

### 4.5 表格

| 部位 | 规格 |
|---|---|
| 表头行 | 白底；顶部 2.25 pt ink；底部 0.5 pt ink；文字 8.5–9 pt 粗体、墨色；设为「标题行重复」 |
| 数据行 | 行间 0.5 pt hairline-2；文字 9–9.5 pt；占位内容用 `〔〕` 并设为 text-2 |
| 末行 | 底部 0.5 pt ink 收口 |
| 竖线 | 不画。例外：信息栏、签字区、组织架构这类「一格一个字段」的表，用 hairline-2 竖线 |
| 无边框 | 用 `nil`，不要用 `none` 加白色（在纸色背景上会显出白线） |
| 分页 | 6 行以内的表整表不拆页（非末行段落设 `keepNext`）；长表允许跨页；每行 `cantSplit` |
| 对齐 | 编号、★ 这类标记居中；金额右对齐；其他左对齐 |

- 合计行的数字用 Bahnschrift 粗体。
- 签字区：标签行加空白行成组排列；首组顶部 2.25 pt ink，组与组之间 hairline-2，最后 0.5 pt ink 收口；整块不拆页。

### 4.6 其他元素

| 元素 | 规格 |
|---|---|
| 填写提示 | 「填写提示」样式，text-2。写给填表人的说明都用它 |
| 占位符 | `〔姓名〕`、`〔YYYY-MM-DD〕`，text-2 |
| 引用 | 左侧 2.25 pt 墨色竖线，文字墨色。这是正文里唯一允许的线，且是竖线 |
| 代码 | Consolas 8.5 pt，code 底色，无边框 |
| 图片占位 | 单格表格（固定行高，无边框）里放一个同大的圆角框：1 pt hairline-2 边、canvas 底，框内居中写「图片占位 · 建议宽度 16 cm」，text-2 |
| 题注 | 9 pt，text-2，左对齐，格式为「图 3-1　〔图题〕」「表 4-1　〔表题〕」 |
| 无序列表 | 符号 `■`，6 pt，墨色 |
| 有序列表 | `1.`，Bahnschrift 粗体，墨色 |
| 参考文献 | `[1]`，Bahnschrift，墨色 |
| 勾选项 | 使用 Word 内容控件复选框（☐ / ☒，Segoe UI Symbol），不要手打括号 |

### 4.7 自动填充标记

`<<<pronumber>>>`、`<<<name>>>`、`<<<usname>>>`、`<<<time>>>`、`<<<ask…>>>` 这类标记由程序用 Word 查找替换来填写（见 2026-014 的 `PRO.cs`）。

- 每个标记必须**原样、完整地放在同一个 run 里**。`<<<ask…>>>` 里的提示词会原文发给 AI，一个字都不能改。
- 标记要用正文墨色，不要用灰色：替换进来的文字会继承标记的格式。
- 标记只放在正文里，不要放进页眉页脚：查找替换只搜正文。
- 改版后要核对每种标记的出现次数与原件一致。

## 5. PowerPoint

- 画布用 `LAYOUT_WIDE`（13.333 × 7.5 in），左右边距 0.6 in。字体规则同 §3。
- **封面**（浅色）：
  - 顶栏：字标 2.0×0.6 in，旁边接圆角墨色条，一直到右边距。母版的矩形做不了圆角，所以字标和墨色条画在封面页上，母版留空。
  - 标题区：英文标签、48 pt 粗体标题、20 pt text-2 副标题。
  - 底部信息栏：顶部粗墨线，三栏分别为制作人、日期、编号，栏间用 hairline-2 竖线。
- **章节页**（墨色背景）：
  - 左上角放纸色字标。
  - 章节号 `01`：Bahnschrift 110 pt，accent-dark。
  - 标题 44 pt 粗体，canvas 色；副标题 18 pt，text-2-dark。
  - 右下角写 `01 / 05`。
- **内容页**（浅色）：
  - 标题 28 pt 粗体，后接圆角墨色条（高 0.46 in），一直到右边距，与 Word 的「标题 1」同一做法。标题上方不加横线。
  - 章节标签反白写在墨色条右端：`01` 用 Bahnschrift、accent-dark，后面接章节名，canvas 色，13 pt。
  - 墨色条是独立形状，左端按标题长度算出。**改了标题要把墨色条的左端拖到标题后面**（留约 0.3 in 间距）。
  - 左下角放墨色小字标，右下角放 Bahnschrift 页码。
  - 目录页同样用「目录 + 墨色条」，条里写「共 N 部分」；各部分编号用 accent。
- **表格**：同 §4.5，表头白底加粗横线，不画竖线。
- **常用版式**：分工表、里程碑（圆角墨色小方块节点）、图文两栏、三栏块、大数字指标、2×2 块、前后对比（「改进后」的占位框用墨色边强调）、难点表、解决路径（圆角流程块，末步用 2.25 pt 墨色边收尾）、甘特图（圆角墨色条）、清单两栏、总结页。
- 块的标题区用顶部粗墨线（线，直角），不用卡片底色。
- 图片占位：圆角框，1 pt hairline-2 边；需要强调时换 1.5 pt 墨色边。

## 6. Excel

- 字体：微软雅黑 10 pt；数字列用 Bahnschrift。关闭网格线。
- **第 1 行**：左侧放墨色字标（140×42 px），右侧合并单元格上盖一个同宽的圆角墨色形状（上下各缩 3 pt，随单元格移动和缩放），作为墨色条；单元格本身不填色。第 3 行写标题，16 pt 粗体，中英并列。
- **标题栏**：一行标签（9 pt，text-2）加一行值（10 pt）。顶部用 thick 墨色边框，底部 medium，字段之间 hairline-2 竖线。标签只写中文，避免被截断。
- **列头**：按 §4.5，白底，顶部 thick 墨色，底部 thin 墨色，粗体墨色，自动换行。
- **数据行**：行间 hairline-2，列间 hairline-2 竖线（清单类表格需要竖线来对齐）。
- **合计**：计算列必须写公式，例如 `=IF(OR(I10="",O10=""),"",I10*O10)`。合计行上下 medium 墨线，合计值用 Bahnschrift 粗体、accent。
- **填写说明**：表格末尾一行 9 pt text-2，说明哪些列要填、哪些列自动计算。
- **打印**：A4 横向，缩放到一页宽，列头设为每页重复，冻结窗格在列头下方。
- 数据校验：固定取值的列（如 RoHS 填 Y / N）用下拉。
- 修订记录页的列头同样是白底、顶部 thick 墨色、底部 thin 墨色。

## 8. 实现要点（踩过的坑）

### 8.1 中文字体被换成等线

Word 另存时会把 `docDefaults` 里的中文字体改写成「跟随主题」（`w:eastAsiaTheme="minorEastAsia"`），而主题默认的中文字体是等线。结果所有没有单独指定字体的文字都会变成等线。

修法：生成后改 `word/theme/theme1.xml`，把 `a:latin` 改为 Segoe UI，把 `a:ea` 和 `script="Hans"` 的字体改为 Microsoft YaHei。

```js
theme.replace(/<a:latin typeface="[^"]*"/g, '<a:latin typeface="Segoe UI"')
     .replace(/<a:ea typeface="[^"]*"/g, '<a:ea typeface="Microsoft YaHei"')
     .replace(/<a:font script="Hans" typeface="[^"]*"/g, '<a:font script="Hans" typeface="Microsoft YaHei"');
```

### 8.2 标题墨色条与圆角块（Word）

docx-js 画不了圆角形状，所以分三步：

1. **docx-js 生成**：墨色条先用「底纹 run + 底纹制表符」占位（标题文字 + `　` + 反白说明 + `\t`，说明与制表符带 ink 底纹，右对齐制表位在内容宽度处）。封面顶栏用单元格填色，图片占位用单格表格的实线框。
2. **Word COM 替换**（`round-word.ps1`）：
   - 找到末尾是 ink 底纹制表符的段落，量出底纹起点在页面上的横坐标，删掉底纹部分，在标题末尾插入圆角形状并转成嵌入型（`WrapFormat.Type = 7`），说明文字写进形状。
   - 在墨色条前插段落标记拆段，墨色条段改用「墨色条」样式（大纲级别为正文），再对标题段调用 `Selection.InsertStyleSeparator()`，把它的段落标记变成样式分隔符。注意这个方法**不是**在光标处拆段，而是把当前段落的段尾变成分隔符，所以必须先手动拆段。
   - 封面顶栏、图片占位：去掉填色或边框，在单元格里放同大的圆角形状（`LayoutInCell`，相对栏与段落定位）。
3. **XML 收尾 + 定长**：`fix_bars.py` 删掉 Word 转嵌入型时在墨色条前自动补的空格 run，并给墨色条 run 加 `w:position`（下沉约 0.4 个条高）；`finish-word.ps1` 再按实测横坐标把每条墨色条补到右边距，更新目录，导出 PDF 验收。

踩过的坑：

- 墨色条不能用浮动形状：相对「行」或「段落」定位时，Word 会把段前间距算进去，而页首的段前间距又会被吞掉，标题一换位置条就偏上或偏下。
- 嵌入型 wps 形状不在 `InlineShapes` 集合里，仍在 `Shapes` 里；用字符索引取到的是它前面那个空格，所以下沉只能在 XML 里设。
- 用 COM 处理时必须**只读打开源文件**，退出用 `Quit([ref]0)`；否则 Word 退出时可能回写源文件。

### 8.3 编号挂到标题样式

docx-js 不支持在样式上挂编号。做法是生成后改 XML：

- 在 `numbering.xml` 对应的 `w:lvl` 中，于 `w:numFmt` 之后插入 `w:pStyle`。
- 在 `styles.xml` 的 Heading 样式 `w:pPr` 中插入 `w:numPr`，位置在 `keepNext` / `keepLines` 之后。
- 无编号标题用 `numId=0` 关掉编号。

子元素的顺序受 schema 约束，放错位置 Word 会报文件损坏。

### 8.4 其他

- 表格「无边框」用 `BorderStyle.NIL`。
- 低分辨率 PDF 渲染时，相邻色块之间会出现浅色细缝。这是抗锯齿伪影：用 300 dpi 取像素核对即可，文档本身没问题。
- 本机没有 LibreOffice。验收渲染走 Office COM：Word 用 `ExportAsFixedFormat`，PowerPoint 用 `SaveAs(…, 32)`，Excel 用 `ExportAsFixedFormat(0, …)`。PDF 用 PyMuPDF 转成图片检查。
- Excel 公式写完后要用 Excel COM 打开并执行 `CalculateFull` 再保存，这样才会有缓存值。
